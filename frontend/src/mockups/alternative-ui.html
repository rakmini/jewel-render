Alternative UI Concepts

Three alternative interface designs targeting the most critical user stories of JewelRender, prioritizing the mobile-first "remote control" paradigm.

1. Rapid Batch Review Loop

Problem: Clicking tiny +/- buttons in a grid is slow for 50+ images.

Solution: A full-screen, immersive swipe interface to rapidly train the Reference Image Library (RIL).

2. Cross-Preset Style Matrix

Problem: Dragging images between tabs feels disjointed and hides context.

Solution: A "long-press" floating radial menu. It shows the current image at the center, surrounded by instant-transfer target styles.

3. Visual Recede (Outpainting)

Problem: A simple 0-50% slider doesn't tell the user what the final composition will look like.

Solution: An interactive "reverse crop" box. You pinch/scale the original image down inside a fixed canvas, visualizing exactly how much AI-generated space will be added.
