Core Workspace

US-01
Upload & Image Queue
As a user I can drop jewelry photos into the queue, see thumbnails, and approve or reject each render with +/− buttons so the AI learns what I want.
drag-and-dropfeedbackqueue
US-02
Preset Selection
As a user I can switch between style presets (Cool Blue, White Retail, Yashica Film) and create, rename, duplicate or delete my own presets.
presetstabsbrand style
US-03
Image Edit Mode
As a user I can upload an existing photo and selectively change specific elements — background, metal colour, stone — while keeping the rest pixel-perfect.
editselective changeinpainting
US-04
Recede — AI Outpainting
As a user with a too-tight product shot I can use the Recede slider to pull back the framing via AI outpainting without reshooting.
outpaintingframingslider
US-05
Image Generation Mode
As a user I can write a text prompt and optionally pick reference images to generate a brand-new product photo in the preset's style from scratch.
generationprompttext-to-image
US-06
360° Video Mode
As a user I can upload three key-angle photos (front, side, 3/4) and generate a seamless rotating MP4 loop of the jewelry.
video360°SV3D

VSCO-Style Image Editor
As a user I can open any rendered image and fine-tune it with light, colour, detail and film controls — plus crop, straighten, rotate and flip — before exporting.

As a user I can view and manage each preset's reference library — images that train the AI's style — with manual upload, auto-approved, and auto-export deposit.
